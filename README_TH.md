# Lung Sound Pair Quiz
เกมจับคู่เสียงปอดจากไฟล์ที่แนบมา มี 4 ข้อ แต่ละข้อมี 4 ตัวเลือก ย้อนกลับแก้คำตอบได้ และส่งคำตอบเพื่อดูคะแนนกับเฉลยรายข้อ พร้อมเสียงและวิดีโอทบทวนที่เล่นซ้ำได้

## ไฟล์โปรเจกต์
- `index.html`, `style.css`, `script.js`
- `lung.png` รูปปอดสำหรับคลิก
- `media/` ไฟล์ MP4 ทั้งเสียงและวิดีโอทบทวน

## เปิดใน VS Code
1. แตก ZIP
2. VS Code → File → Open Folder → เลือก `Lung_Sound_Pair_Quiz`
3. ติดตั้งส่วนขยาย Live Server
4. คลิกขวา `index.html` → Open with Live Server

## GitHub Pages
อัปโหลดไฟล์ทั้งหมดรวม `media/` และ `lung.png` ไปยัง repository จากนั้น Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save

## หมายเหตุสำคัญ
ต้นแบบนี้สุ่มฝั่งเสียงผิดปกติซ้าย/ขวาเพื่อจำลองการฝึก และใช้ชื่อไฟล์ตามที่ได้รับมา ผู้สอนควรตรวจสอบว่าเสียงแต่ละไฟล์ตรงกับป้ายชื่อและเฉลยที่ต้องการก่อนนำไปใช้ประเมินจริง การสุ่มตำแหน่งไม่ได้ยืนยันตำแหน่งเสียงทางคลินิกจริง
